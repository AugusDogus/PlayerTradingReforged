# 1.0.0

- Trade directly with nearby players, with offer confirmation, stack splitting, quick move, and controller support.
- View each other’s inventories and equipped items in an aligned trading interface.
- Keep offered items visible as grey reservations in both players’ inventory views.
- Show current weight, carrying capacity, and projected weight after the trade.
- Recover offered items after cancellation or interruption, including full-inventory overflow.
- Configure the trade modifier key and reposition the interface with F11.
- Support Valheim 1.0.12 with BepInEx 5.4.2350. Both traders install the mod; no server installation or Jötunn required.

Original Player Trading code and interface by [projjm](https://github.com/projjm/Valheim-Player-Trading).
