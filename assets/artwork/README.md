# Artwork

Original icon and banner for Player Trading Reforged.

- `icon-source.png`: full-resolution icon source; `../../package/icon.png`: 256 × 256 package icon.
- `banner-source.png`: full-resolution banner source; `../../package/banner.png`: 1200 × 400 README banner.

Exports are resized with ImageMagick. The artwork was created with the built-in image tool using the following prompts.

## Icon prompt

Use case: logo-brand. Create an original square app icon for the Valheim mod Player Trading Reforged, intended for a 256x256 Thunderstore thumbnail. A bold central emblem of two clasped hands wearing simple Viking leather bracers, framed by two broad circular exchange arrows made of warm forged bronze. Dark pine-green background, cream highlights and bronze, restrained Norse fantasy styling with clean illustrated shapes, crisp dark outlines and subtle metal texture. Strong silhouette, generous safe margin, simple enough to read at small size. No text, no letters, no watermark, no existing game logos. Square 1024x1024 artwork.

## Banner prompt

Use case: style-transfer. Redesign the provided Player Trading Reforged project banner as a clean flat graphic. Preserve the exact name "PLAYER TRADING" and "REFORGED", wide 3:1 format, and broad emblem-left/title-right arrangement. Replace the entire misty landscape with a perfectly uniform solid dark pine-green background (#203d35). Replace embossed gold lettering with flat warm cream serif typography, with consistent strokes and generous spacing; PLAYER TRADING on one large line and REFORGED on a smaller line beneath it. Redraw the handshake and two exchange arrows as a very simple flat two-color emblem, warm cream and muted ochre, using clean economical shapes and a few dark-green lines to separate the hands. No detailed leather bracers or knotwork. Treat this like restrained professionally typeset open-source project branding, with a compact emblem, generous outer margins, and substantial negative space. All fills must be completely flat and matte. Remove ALL textures, gradients, metallic rendering, shadows, bevels, highlights, forests, mountains, moons, ornamental rules and photorealism. No additional words. Final canvas 1536x512.

Selected direction: Flat (#1). The original banner was the visual reference for this redesign.
